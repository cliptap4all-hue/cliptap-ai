🍏 מרכז הפצה ל-TestFlight (Mac)

הקוד המלא כולל את פרויקטי ה-iOS (Xcode) וה-Android (Gradle) מוכנים להפצה בחנויות.

פקודת פתיחה ישירה ב-Xcode במק:
npm run cap:sync && npm run cap:ios
פרטי מזהה האפליקציה (Bundle ID):

שם האפליקציה: ClipTap AI
GitHub Repository: cliptap4all-hue/cliptap-ai ↗
איך להעלות ל-TestFlight ב-3 קליקים:
  1. ב-Xcode בחר יעד: Any iOS Device (arm64).
  2. בתפריט העליון לחץ Product > Archive.
  3. בחלון שייפתח לחץ Distribute App > TestFlight.
